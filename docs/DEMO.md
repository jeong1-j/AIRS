# Windows 시연 및 판별 시험

[AIRS v1.2.8 실행 파일](https://github.com/jeong1-j/AIRS/releases/tag/v1.2.8)

[시연 영상](https://github.com/jeong1-j/AIRS/releases/download/v1.2.8/AIRS-Demo-Enhanced-v1.2.8.mp4) · [발표 자료](https://github.com/jeong1-j/AIRS/releases/download/v1.2.8/AIRS-Presentation-v1.2.8.zip)

1. AIRS를 실행하고 **화면 감지 시작**을 누릅니다.
2. ChatGPT Windows 앱에서 `풀어빨리`를 입력하되 보내지 않습니다.
3. `3x+2=11이야. 풀어빨리.`처럼 조건을 넣어 달라지는 안내를 확인합니다.
4. `내가 3x=9까지 정리했어. 다음 단계 힌트만 알려 줘.`처럼 고칩니다. 경고 직후 수정하거나 햄스터 집의 **내가 쓴 질문 확인**을 이용합니다.
5. **햄스터 집**에서 씨앗 간식을 주고 **주간 통계**를 확인합니다.

| 대표 시험 입력 | 기대 결과 |
| --- | --- |
| 정답만 알려 줘. | 답만 요청 |
| 내가 계산했고 비교하려고 정답만 알려 줘. | 신호 없음 |
| 이 실험 보고서 결론을 대신 써 줘. | 과제 맡기기 |
| 검산할 필요 없어. | 검증 생략 |
| 정답 말고 힌트만 줘. | 신호 없음 |
| 빨리 해 줘. | 신호 없음 |
| 풀어빨리 | 과제 맡기기 |
| ‘정답만 알려 줘’라는 문장이 왜 문제인가요? | 신호 없음 |
| 내가 3x=12까지 풀었어. 다음 단계 힌트만 알려 줘. | 신호 없음. 좋은 질문 기준 충족 |

v1.2.8 배포 실행 파일의 판별 함수를 대상으로 위 문장 9개를 검사해 9개가 기대 결과와 일치했습니다. v1.2.8 앱의 질문 확인에서 미적립 질문의 보상 10알, 동일 질문의 중복 적립 방지, 간식 사용 후 호감도 1점, 일별 3건 집계(신호 2건, 스스로 확인 1건)를 검사했습니다. 이 시험은 앱 기능의 동작 확인이며, 교육 효과는 실제 사용자 질문의 수정 전후 기록으로 확인합니다.
